Is this email a burner?

Paste one email address or a domain. BurnerCheck tells you if it is a disposable (throwaway) inbox, a role address like info@ or admin@, a free webmail provider, or badly formed, and suggests a fix for common typos like gamil.com.

Free: about {{ANON_PER_MIN}} checks per minute. Tip: check just the domain if you prefer; domain mode never sends the part before the @.

    How it works
    
    
      
      
    • Disposable: the domain (or a parent domain) is on the open-source disposable-email-domains list (CC0), {{DOMAIN_COUNT}} domains, version {{LIST_VERSION}}. A small allowlist overrides known false positives. It is list-based: brand-new throwaway domains are missed until the list adds them.
      • 
      
    • Role: the part before the @ is a shared or system mailbox (info, admin, support, sales, noreply …).
      • 
      
    • Free provider: Gmail, Outlook/Hotmail, Yahoo, iCloud, Proton, GMX and other consumer mail.
      • 
      
    • Lookalike: domains that mix alphabets (for example a Cyrillic "а" in "gmаil.com") are flagged.
      • 
      
    • Syntax: a practical address check. BurnerCheck does not look up MX/DNS records or contact any mail server, so a valid format doesn't mean the mailbox exists.
      •

    For AI agents (MCP)
    
    
    BurnerCheck is also a remote MCP server for AI agents: check_email, check_domain and get_meta, read-only, same list, keys and limits as the API. Add it to an MCP client that supports remote (Streamable HTTP) servers:
    
    
    { "mcpServers": { "burnercheck": { "type": "http", "url": "https://burnercheck.mike-tusa.workers.dev/mcp" } } }
    
    
    Some clients use a different format (for example VS Code uses a servers key). No key needed; add "headers": { "Authorization": "Bearer bc_live_…" } for higher limits. Machine-readable: llms.txt · OpenAPI 3.1.
